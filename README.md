# HR Attrition Analysis Dashboard — Excel

## 📌 Project Overview
Analysis of IBM HR Attrition dataset of 1,470 employees 
to identify patterns driving employee attrition.

## 🎯 Key Finding
Employees who left had 30% lower average salary 
(₹4,787) vs those who stayed (₹6,832)

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables & Slicers
- VLOOKUP, XLOOKUP, INDEX MATCH
- COUNTIF, SUMIF, COUNTIFS, SUMIFS
- Data Visualization & Dashboard

## 📊 Dashboard Includes
- KPI Cards — Total Employees, Attrition Rate, Avg Salary
- Department wise Employee Count — Bar Chart
- Attrition Yes vs No — Pie Chart
- Average Salary vs Attrition — Column Chart
